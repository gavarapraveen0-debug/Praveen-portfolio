Praveen's Personal Portfolio Website

About the Project

This project is a personal portfolio website developed using HTML5 and CSS3. It introduces me, highlights my technical skills, showcases my projects, and provides contact information.

Features

- Home section with a personal introduction
- About Me section with education and career interests
- Skills section showcasing technical skills
- Projects section displaying academic projects
- Contact section with contact information
- Responsive layout for desktop and mobile screens
- Navigation links to different sections of the website

Technologies Used

- HTML5
- CSS3
- CSS Flexbox and Grid
- CSS Media Queries

Project Structure

- "index.html" – Contains the website structure and content.
- "style.css" – Contains the styling, layout, and responsive design.
- "project-description.txt" – Contains the project description.
- "screenshots/" – Contains desktop and mobile screenshots.

How to View the Project

1. Open "index.html" in a web browser to view the website locally.
2. If the website is hosted using GitHub Pages, open the published website link.

Project Purpose

The purpose of this project is to practise HTML and CSS fundamentals, semantic webpage structure, styling, layout design, and responsive web development.
